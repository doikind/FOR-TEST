## Purpose

统一管理所有候选内容（热点候选与二次创作候选）的待审核、采用与驳回流程，实现五状态人工审核、审核动作留痕与透明规则反馈，将人工决策转化为规则权重调整并在 UI 展示，形成"选题→审核→学习"闭环。

## ADDED Requirements

### Requirement: 候选内容入池与状态机
系统 SHALL 接受来自热点发现与内容创作两条管线的候选内容进入统一待审核池；候选状态 SHALL 为 Draft、Needs Revision、Pending Review、Approved、Rejected 之一；同一事件的去重键（topic_key）已存在时 MUST 拒绝重复入池；每项候选 MUST 携带来源、类目、优先级、风险等级、状态与真实性标签字段。

#### Scenario: 两条管线入池
- **WHEN** 热点管线与创作管线分别产出候选
- **THEN** 二者进入同一个待审核池，池中每条记录可区分来源（hot_topics / content_creation）与真实性标签

#### Scenario: 重复候选被拒
- **WHEN** 待审核池已存在相同 topic_key 的候选
- **THEN** 系统拒绝再次入池并返回去重提示

#### Scenario: 状态流转
- **WHEN** 候选通过内容安全检查（LOW 或修改后的 MEDIUM）进入审核
- **THEN** 状态为 Pending Review；人工可将其改为 Needs Revision（填修改意见）、Approved 或 Rejected

### Requirement: 人工审核与自动发布禁止
所有账号操作（采用、驳回、模拟发布）MUST 由人工在 UI 确认；系统 MUST NOT 自动采用或发布任何内容；只有人工点击 Approve 后，内容才能进入内容资产库；本项目不进行真实 X 发布，只展示发布预览与人工确认流程；LOW 风险候选仅允许进入人工审核，系统 MUST NOT 自动批准。

#### Scenario: 人工批准
- **WHEN** 用户在 UI 点击 Approve
- **THEN** 候选状态更新为 Approved，并记录审核动作与审核时间，内容进入资产库

#### Scenario: 人工驳回
- **WHEN** 用户在 UI 点击 Reject 并填写原因
- **THEN** 候选状态更新为 Rejected，驳回原因被持久化供后续复盘

#### Scenario: 驳回后修改
- **WHEN** 用户点击"需要修改"并填写修改意见
- **THEN** 候选状态更新为 Needs Revision，修改意见被持久化

#### Scenario: 自动操作被禁止
- **WHEN** 任何自动化流程尝试将候选状态改为 Approved 或模拟发布
- **THEN** 系统拒绝该操作，仅允许人工触发状态变更

### Requirement: 审核记录可追溯
系统 SHALL 持久化全部审核动作（候选、动作、审核时间、采用或驳回、驳回原因、修改意见），支持按状态、来源、类目筛选查询。

#### Scenario: 查询历史审核记录
- **WHEN** 用户按状态或来源筛选待审核池
- **THEN** 系统返回匹配记录及完整审核历史（动作、时间、原因、意见）

### Requirement: 反馈回流与权重展示
系统 SHALL 基于历史采用/驳回记录进行透明规则权重调整：某类选题被采用时相关特征权重 +0.05，被驳回时 -0.03，累计范围 MUST 限制在 -0.10 ~ +0.10；该调整 MUST NOT 被称为模型训练或 AI 自学习；后续优先级排序 SHALL 应用调整后的权重，且 UI MUST 展示权重变化（调整前/后对比）。若权重调整影响 P0 进度，系统 MAY 降级为仅记录决策（不应用权重），但决策记录 MUST 保留。

#### Scenario: 采用后权重上调
- **WHEN** 某类目选题被人工采用
- **THEN** 该类目相关特征权重 +0.05（累计不超过 +0.10），后续排序使用新权重，UI 展示权重变化明细

#### Scenario: 驳回后权重下调
- **WHEN** 某类目选题被驳回并记录原因
- **THEN** 该类目相关特征权重 -0.03（累计不低于 -0.10），并展示调整依据（驳回原因归类）

#### Scenario: 权重范围限制
- **WHEN** 权重累计达到 -0.10 或 +0.10 上限
- **THEN** 系统停止进一步同向调整，保持在上限值

#### Scenario: 权重变化可视化
- **WHEN** 用户在 UI 查看反馈统计
- **THEN** 展示各来源/类目的采用率、驳回率、权重调整前/后值，且不得标注为"模型训练/自学习"

#### Scenario: 降级为仅记录决策
- **WHEN** 权重调整实现影响 P0 进度
- **THEN** 系统仅记录采用/驳回决策（决策记录保留），暂不应用权重调整，并在 UI 说明
