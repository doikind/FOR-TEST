大家好，我介绍 FinSignal 的第一个 Agent：每日热点 → 候选内容池。

【产品需求解读】目标账号是面向东南亚英文市场、新加坡为中心的 AI 金融出海品牌。内容运营最痛的是：热点靠人工刷屏，效率低；候选没有审核沉淀，好点子用完就丢。这个 Agent 把"热点发现 → 内容创作 → 审核沉淀"产品化，让运营每天打开页面，就能看到真实数据筛出的热点和候选内容。

【工作流设计】七步管线：真实采集 Google News、GDELT、Hacker News，官方媒体白名单过滤；TF-IDF 去重；热度、时效、类目、反馈四维加权排序，每条展示理由；按可编辑账号画像判断相关性；自动生成中文翻译、主题、角度；改编引擎产出原创英文文案，不照搬原文；风险检查后入池。【演示】点"采集热点"，可见实时数据和去重数量。

【UI 理念】透明、可解释、可控。每条数据带真实性标签——实时、快照、模拟用徽标区分；排序和判断都有理由；免责声明常显。账号画像可编辑、保存、切换，切换后整条管线实时重算。

【AI 使用方式】AI 封装成独立 Provider：有 Key 走实时模型，命中缓存标注复用，无 Key 回退规则模板，全程标注生成方式，不冒充实时模型。

【人工审核点】候选走五状态审核流：草稿、需修改、待审核、通过、驳回。系统永不自动批准，必须人工 Approve 才进资产库；驳回填原因、修改填意见；高风险直接 Blocked。每次采用或驳回还作为监督信号喂给在线学习模型，让排序越用越准。

【当前局限】无 API Key 时文案质量有上限；免费接口采集量有限；在线学习需积累审核样本。

【后续优化】优先三件事：接入真实大模型增强改写；扩充地区预设和来源白名单；与 Agent 2 的爆款模板打通，形成完整闭环。
