# 3 分钟 Demo 演示脚本

> 演示前准备：`pip install -r requirements.txt`，然后 `streamlit run app.py`，浏览器打开 `http://localhost:8501`。

## 0:00–0:30 开场与产品定位

"这是 FinSignal Content Agent——面向东南亚英文市场、以新加坡为中心的 AI 金融内容候选系统。它把笔试第 2 题（热点到候选池）和第 5 题（爆款拆解与二次创作）合并成同一个闭环。所有数据都是真实公开数据，所有模拟数据都明确标注，任何内容都不自动发布。"

## 0:30–1:10 热点发现（第 2 题前半）

1. 打开「热点发现」页，点击**采集今日热点**
2. 展示：采集 N 条 → 去重后 M 条；来源状态（Google News / GDELT / Hacker News），若有失败来源显示失败原因
3. 打开第一条事件，展示：**原始 URL、采集时间、真实性标签 `live_public`**
4. 展示优先级分数与排序理由（热度/时效/类目/反馈校正四因子）
5. 展示跟进判断：`follow / consider / caution / skip` + 理由
6. 点击**生成摘要与角度**，展示事件摘要与英文内容角度

## 1:10–1:45 爆款拆解（第 5 题前半）

1. 切到「爆款拆解」页，展示 Finimize 对标数据，**红色徽标 `simulated_demo · 模拟数据`**
2. 展示：高表现 3 条 vs 普通 3 条，**相对表现分数**（不是点赞绝对值）
3. 展示六维度拆解表：Hook/结构/信息密度/CTA 等，每项标注 `OBSERVED`
4. 展示证据分级说明：OBSERVED / INFERRED / UNKNOWN，强调"相关性≠因果"

## 1:45–2:15 二次创作与风险检查（第 5 题后半）

1. 切到「二次创作」页，输入真实洞察标题，点击**生成候选**
2. 展示 **≥3 条原创英文候选**，每条含：角度、目标互动、正文、Hook、结构、CTA、事实来源
3. 展示每条候选的**相似度检查**分数与**风险等级**（LOW/MEDIUM/HIGH）
4. 强调页面常显免责声明 "This content is for informational purposes only..."

## 2:15–2:45 人工审核与资产库（闭环汇合点）

1. 切到「待审核池」，展示候选列表与五状态
2. 演示**人工 Approve**（强调：只有人点 Approve 才入库，无自动发布）
3. 展示审核记录与反馈权重变化（规则调整，非模型训练）
4. 切到「内容资产库」，演示**模拟发布**（录入表现，`simulated_demo` 标注）

## 2:45–3:00 收尾

"总结：真实数据闭环、产品判断（跟进决策）、人工审核、可运行可演示。不做空壳大模型聊天框，每个环节都有真实逻辑。"

## 备注

- 若实时源失败，演示「加载真实公开数据快照」（`cached_public`）兜底，强调"绝不伪造新闻"
- 所有模拟数据（Finimize 对标、模拟发布表现）都带 `simulated_demo` 徽标
