大家好，我介绍第二个 Agent：爆款拆解 → 二次创作。

【产品需求解读】运营爆款账号的困境：知道某条帖子爆了，但说不清为什么爆；经验散落在个人记忆，换个人就丢。这个 Agent 把"爆款为什么火"拆解成可复用结构模板，再基于真实洞察二次创作，让经验变成团队方法。

【工作流设计】四步。一，X 内容发现：解析对标账号真实公开推文，拿不到时回退仓库真实快照。强调：系统不虚构互动数据——X 对匿名访客不开放完整点赞数，所以表现分数基于长度、信息密度、emoji、结构、CTA 等可观察特征计算，互动标注 UNKNOWN。二，同账号内高表现 vs 普通对比，用相对分数避免大号天生爆款偏差。三，六维度拆解：选题、Hook、结构、信息密度、CTA、互动设计，结论标注证据等级 OBSERVED、INFERRED、UNKNOWN。四，沉淀结构模板。【演示】选 FintechSG：自动抓取、筛选、拆解。

【UI 理念】三步流程：发现拆解、洞察沉淀、二次创作。账号下拉预置 AlphaSense、Finimize 及新加坡的 FintechSG、MAS_sg，切换自动重拆解；高表现和普通内容并排对照，证据分级用颜色区分。

【AI 使用方式】与 Agent 1 同一套 Provider。关键是拆解出的高表现特征会实际驱动新文案——高表现爱用问句，新 Hook 就改问句；爱用数字，正文就织入数字事实。基于真实洞察生成至少三条原创英文候选，不照搬对标原句。

【人工审核点】候选进入与 Agent 1 共用的待审核池，同一五状态审核流：人工批准才入库，驳回填原因、修改填意见，高风险禁入库。模拟发布表现标注 simulated_demo，不冒充真实成绩。

【当前局限】拿不到 X 真实互动计数，表现分数是间接信号；镜像不稳定会回退快照；模拟表现只是预估。

【后续优化】优先三件事：接入真实 X 数据源，把互动从 UNKNOWN 变可验证；支持多账号横向对比；用更强模型增强拆解深度和文案质量。
